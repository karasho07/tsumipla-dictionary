# 積みプラ手帳 辞書配信

Androidアプリ「積みプラ手帳」向けJAN辞書の配信データです。
基準バージョン：2026-10-15.1。1,759商品、2,189件のJAN。

辞書の追加・修正は公式情報と照合し、運営者が確認してから反映します。自動収集処理と、このパソコンで使う運営画面を同梱しています。
商品画像、説明文、公式ロゴは配信していません。バンダイの公式アプリではありません。
このリポジトリには所持品データやアプリの署名鍵を含みません。

## 運営画面の使い方

1. 「運営画面を開く.cmd」をダブルクリック（Python 3.10以降が必要。CodexのPythonがあれば自動利用、なければpy -3）。
2. 「最新辞書と毎日の候補を取得」を押す。初回組み込み前は手元の辞書の方が新しいため同期を拒否します。
3. 候補の名前・JAN・発売日と公式リンクを確認し、選択して「承認」または「保留」。要確認の候補は承認できません。
4. 「承認分の配信ファイルを作る」でZIPをダウンロード。書き出す前にも公式情報と配信中の辞書を再確認します。
5. ZIPを展開し、中の4ファイルを一度のコミットでGitHubのmainへアップロードします。ZIP自体はアップロードしません。ここが利用者向けの公開操作です。
6. 公開後は「最新辞書と毎日の候補を取得」で基準を更新。古い辞書での承認は次版に持ち越しません。

「公式情報を収集する」で随時の収集も可能です。終了は起動したコマンド画面でCtrl+C。起動用URLは共有しないでください。承認・保留はローカルの.operatorに保存します。

## 毎日の自動収集

.github/workflows/collect-jan.ymlをmainに配置すると、毎日日本時間6:17を目安にGitHub Actionsが実行します。GitHubの混雑による遅延、長期無操作によるschedule停止はあり得ます。「Actions → JAN候補を毎日収集 → Run workflow」で随時実行できます。

結果はjan-candidatesブランチのreports/latest.jsonとActionsのArtifactsへ保存します。mainの辞書には自動反映しません。標準GITHUB_TOKENだけを使用し、個人のAPIキーやアクセストークンは不要です。リポジトリのActionsポリシーで書き込みが制限されている場合は設定が必要です。

公式ガンプラカテゴリの最新60件から、1回最大30件を説明書サイトで照合。確認窓は日ごとに回転します。公式商品コードから抽出した13桁は候補にとどめ、チェックデジット・JAN検索の単一結果・商品名の一致を確認した場合のみ承認可能にします。既存の同一説明書がある場合は商品IDを再利用します。

発売日は日まで分かる場合のみ収録。既知JANの発売日空欄は補完候補とし、登録済み日付は上書きしません。名称差異・複数一致・商品ID競合・未掲載・解析失敗は保留対象。付属品・デカール等も公式カテゴリに含まれ、候補へ現れる場合があります。収録対象かは運営者が判断します。

全歴史商品の網羅、すべての限定品、他社製品、JAN未掲載商品の予測には対応しません。最低3秒のホスト別間隔、robots.txt確認、20時間キャッシュ、タイムアウト・サイズ上限を設けています。画像・商品説明・説明書PDFは収集しません。robots.txtへの対応は情報再配布の許諾を意味しません。

## 配信と検証

配信ZIPはバージョン付き固定ファイル（例gunpla_dictionary_2026-10-16.1.json）、互換用gunpla_dictionary.json、manifest、承認監査ファイルの4点です。旧manifestと新辞書の混在を防ぐため、manifestは固定ファイルを参照します。過去のバージョン付きファイルは削除・上書きせず残してください。

商品ID削除・既存JANの付け替え・未確認候補の公開は拒否します。承認は収集時の辞書ハッシュに結び付け、基準辞書や候補内容が変われば再確認を要求します。SHA-256は整合性の確認であり、収集元による署名や利用許諾ではありません。

開発時の実行コマンド：

```text
python -m unittest discover -s tests -v
python tools/dictionary_ops.py validate
python tools/dictionary_ops.py collect --output reports/latest.json
python tools/dictionary_ops.py serve
```

追加パッケージは不要。画面は127.0.0.1のみで待ち受け、起動ごとのランダムトークン、Host/Origin検査、CSP、テキスト描画で保護します。外部公開サーバーには使用しないでください。.operatorにはキャッシュと承認状態があり、GitHubに含めません。

初回はtools、tests、.github/workflows、.gitignore、起動cmd、README、gunpla_dictionary.json・バージョン付き固定辞書・manifestを組み込みます。Actionsで初回実行と候補専用ブランチへの保存を確認して、初めて自動収集が稼働したと判断します。

アプリはHTTPS、SHA-256、件数、形式、既存の商品IDとJAN対応を検証し、新しい辞書のみ適用します。
通常版と限定仕様は別商品として扱います。名称はメーカー側の表記変更などで修正される場合があります。

一般公開に向け、収集元の利用条件・再配布条件の確認とデータの再監査を継続します。
