# 積みプラ手帳 辞書配信

Androidアプリ「積みプラ手帳」向けJAN辞書の配信データです。
バージョン：2026-10-08.4。収録JAN：2,154件。

辞書の追加・修正は照合してから反映します。新作のJANを自動収集する仕組みは未実装です。
商品画像、説明文、公式ロゴは配信していません。バンダイの公式アプリではありません。
このリポジトリには所持品データやアプリの署名鍵を含みません。

## 更新手順

1. 商品情報とJANを照合して gunpla_dictionary.json を更新する。
2. 既存の商品ID・JANの対応を維持し、dictionary_version を YYYY-MM-DD.N 形式で増やす。
3. dictionary_manifest.json のバージョン・商品数・JAN数・SHA-256を更新する。
4. 両ファイルを同じコミットで配置する。

アプリはHTTPS、SHA-256、件数、形式、既存の商品IDとJAN対応を検証し、新しい辞書のみ適用します。
通常版と限定仕様は別商品として扱います。名称はメーカー側の表記変更などで修正される場合があります。

一般公開に向け、収集元の利用条件・再配布条件の確認とデータの再監査を継続します。
